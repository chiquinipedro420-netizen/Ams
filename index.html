Python é fácil para iniciantes?

Sim. Python é considerada uma das melhores linguagens para começar porque: a sintaxe parece “inglês” exige menos código possui enorme comunidade e documentação

Qual a diferença entre Python 2 e Python 3?

Python 2 foi descontinuado. Python 3 é a versão atual e recomendada. Hoje praticamente todos os projetos usam Python 3

O que é pip?

pip é o gerenciador de pacotes do Python. Serve para instalar bibliotecas. Exemplo:pip install requests
